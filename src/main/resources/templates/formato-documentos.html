Funcionalidad en desarrollo

Por ahora puedes seleccionar el formato Estándar como base para tus documentos. Los formatos Compacto y Detallado estarán disponibles próximamente.

Formato activo: Estándar

📄 Estándar

✅ Disponible

Formato clásico peruano de facturación electrónica. Logo + datos de empresa arriba-izquierda, recuadro tipo de documento arriba-derecha, tabla de ítems, totales, leyenda.

🏢
✓ Logo de empresa ✓ Datos completos del emisor ✓ Tabla de ítems detallada ✓ Desglose de impuestos ✓ Leyenda y QR (futuro)

📋 Compacto

🚧 Próximamente

Diseño condensado: logo pequeño, datos en 2 columnas, tabla densa. Ideal para documentos con muchos ítems que necesitan caber en una sola página.

🏢
✓ Logo compacto ✓ 2 columnas de datos ✓ Más ítems por página ✓ Ideal para volumen

📑 Detallado

🚧 Próximamente

Diseño premium con más separación, datos del cliente destacados, secciones con bordes visibles. Ideal para facturas de servicios profesionales y consultorías.

🏢
✓ Logo grande + destacado ✓ Secciones con bordes ✓ Cliente prominente ✓ Más espacio y legibilidad ✓ Look premium
💡
¿Cómo funciona?

El formato seleccionado se aplicará a todos los PDFs generados desde el sistema: tanto en la descarga desde "Mis Facturas" como en la vista previa del wizard. Puedes cambiar el formato en cualquier momento desde esta página o desde ⚙️ Configuración → Preferencias.
